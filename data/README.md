# Data

`credit_card_default.csv` is the *Default of Credit Card Clients* dataset (2.9 MB), committed to the repo
so the dashboard works online without downloading anything.

- Original source: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- Citation: Yeh, I. C., & Lien, C. H. (2009). The comparisons of data mining techniques for the predictive accuracy
  of probability of default of credit card clients. *Expert Systems with Applications*, 36(2), 2473–2480.
- 30,000 rows × 25 columns; the target column was renamed from `default payment next month` to `default_next_month`.
- Amounts are in New Taiwan dollars (NT$).
